# 07 创意素材库

> 状态：`PLANNED`
## 这一部分用来做什么

它负责保存“可以用于创作的想法与技法”，例如：

- 金手指、能力或系统；
- 剧情套路和冲突结构；
- 场景种子和氛围；
- 人物钩子、秘密和关系张力；
- 世界观创意；
- 写作技法、优秀范例与**负向禁写范例（Anti-Pattern）**；
- 伏笔种子与悬念构思。

> 它不是原著事实库，也不是项目当前状态库，严禁将其作为原著客观事实召回。

---

## 素材类型枚举

- `power_hook`：金手指、能力、外挂或限制设定；
- `plot_pattern`：剧情套路、冲突模板、反转结构；
- `scene_seed`：场景画面、微观动作、情绪渲染种子；
- `character_hook`：人物缺陷、怪癖、说话习惯与关系张力；
- `worldbuilding`：架空地理、宗规、法则等灵感碎片；
- `trope`：网络文学母题与高频桥段；
- `technique`：视角控制、节奏压缩、白描或心理描写技法；
- `reference`：可作为文笔参考的优质原著或外部小说片段；
- `anti_pattern`：**负向禁写范例**（如油腻对白、出戏网络梗、生硬堆砌），用作 Prompt 的严厉负向约束；
- `foreshadowing_seed`：计划在某处埋设的长线悬念种子。

## 与原著事实的严格边界

- “原著第 8 章角色 A 失去能力”是客观断言（`claim`）；
- “失去能力后被迫依赖死敌”是冲突套路（`plot_pattern`）；
- “用逐渐崩裂的玉佩象征决裂”是场景种子（`scene_seed`）；
- “主角拥有一个能预知 3 秒后危机的石符”是金手指（`power_hook`）；
- “严禁在生死对决中说冷笑话”是负向约束（`anti_pattern`）。

它们之间可以通过 ID 建立参考链接，但查询类型完全隔离：查询事实绝不混入素材，查询素材绝不作为原著依据。

---

## 负向范例（Anti-Pattern）的实战价值

在 `novel-Skill` 驱动大模型创作时，大模型往往容易产生模式化废话（如重复“倒吸一口凉气”、“嘴角泛起一丝冷笑”）。
将这些常见毒瘤记录为 `anti_pattern`，并在 Prompt 中加入：
> “【负向约束】：严禁采用如下表达方式：[负向范例列表]”

评测证明，明确告诉模型**不要写什么**，对文风质量的提升幅度远超单向塞入优秀正向范例。
